# AI and Automation Portfolio

Practice projects built during the TS Academy AI & Automation course by Okiemute Isaac Okoro.

## Projects

AI Sales Assistant: Prompt Engineering
A prompt-engineered AI sales assistant for a fictional credit organization, written with the Role, Task, Context, Format framework. It was tested with six scenarios (approval guarantees, interest rates, sensitive data, an angry client, an ineligible client, repayment calculations) and refined over four versions.

**Highlights:** structured testing, failures found and fixed, guardrails against promises, invented figures, and sensitive data.
